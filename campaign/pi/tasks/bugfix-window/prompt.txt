`window.py` computes rolling statistics, but both functions emit a trailing partial window: they iterate every index and take whatever slice is left, so `rolling_max([1, 3, 2], 2)` returns `[3, 3, 2]` and `rolling_mean([2, 4], 2)` returns `[3.0, 2.0]`. The tests in `test_window.py` expect only complete windows (`[3, 3]` and `[3.0]`). Fix both functions so they emit one result per full window, keep the `ValueError` for a non-positive window, and run the tests.
